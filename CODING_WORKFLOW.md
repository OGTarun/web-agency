\# OG Studios Development Workflow



Before every task:



1\. Read OG\_RULES.md.

2\. Read PROJECT\_CONTEXT.md.

3\. Analyze the existing files before modifying them.

4\. Never replace working code unnecessarily.

5\. Improve existing architecture whenever possible.



When writing code:



\- Think like a senior frontend engineer.

\- Think like an Awwwards-winning creative developer.

\- Prioritize performance.

\- Keep components modular.

\- Keep imports clean.

\- Never leave placeholders.

\- Never generate incomplete code.

\- Always finish the task completely.



After finishing:



\- Explain what changed.

\- Mention any performance improvements.

\- Mention any files created or modified.

\- Warn if any manual steps are required.
