# OG Studios - Coding Rules

## Mission

Build an award-quality digital agency website.

Every feature should feel premium, polished, and production-ready.

Never generate generic landing pages.

---

# Tech Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- React Three Fiber
- Drei
- Postprocessing

---

# Design Language

Inspired by:

- Apple
- Framer
- Linear
- Vercel
- Awwwards

---

# Theme

Dark

Minimal

Luxury

Futuristic

Cinematic

---

# UI Rules

Use spacing generously.

Use glassmorphism only where it improves hierarchy.

Avoid visual clutter.

Use subtle gradients.

Typography should feel expensive.

Animations must be smooth.

No harsh motion.

Everything should have purpose.

---

# Components

Keep components reusable.

Never create giant files.

Split logic whenever appropriate.

Prefer composition.

---

# Performance

Lazy-load heavy components.

Avoid unnecessary renders.

Keep animations GPU-friendly.

Optimize Three.js scenes.

---

# Code Quality

Always use TypeScript.

Never leave TODOs.

Never leave placeholders.

Never break existing imports.

Never duplicate code.

Always produce production-ready code.

---

# Animation Rules

Motion should feel premium.

No excessive bouncing.

Use easing.

Use interpolation.

Prefer subtle motion over flashy effects.

---

# Three.js Rules

Lighting should be cinematic.

Objects should react smoothly to mouse movement.

Performance is more important than polygon count.

Always optimize materials.

---

# Final Goal

The website should look good enough to compete on Awwwards.
